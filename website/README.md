# Mneme website

The public Mneme site is a standalone Next.js App Router project with Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repository in Vercel and set **Root Directory** to `website`.
Vercel detects Next.js automatically and uses `npm run build`; no `vercel.json`
or environment variables are required for this static-first site.
